# Home Elevated

PMC Homepage — Anti-AI, Soft Morphing, Award-Level Product Design Prompt

Create the homepage for PMC — Property Management Company, a premium real-estate and property-management platform.

This must look like it was designed by an elite human product designer and art director, not generated from a modern SaaS template.

The result must feel original, tactile, soft, intelligent, editorial and expensive.

CRITICAL DIRECTION

Do NOT create an "AI website."

Do NOT create a typical startup landing page.

Do NOT create:

floating gradient blobs

glassmorphism

neon effects

purple/blue gradient backgrounds

glowing cards

excessive soft shadows

generic dashboard cards

huge centered hero text

giant input fields

oversized buttons

random decorative 3D objects

abstract AI illustrations

meaningless geometric shapes

repetitive cards

generic real-estate template layouts

stock SaaS component libraries

excessive iconography

The design must feel human-designed and intentionally art-directed.

Think:

high-end architecture magazine + sophisticated consumer product + premium financial interface + modern property technology

Not:

AI SaaS landing page

DESIGN PHILOSOPHY

The interface should feel like a physical object designed beautifully.

Everything should have:

soft rounded geometry

subtle depth

tactile interaction

calm hierarchy

excellent typography

visual rhythm

intelligent information density

Use softness without becoming bubbly.

Use roundness without turning everything into pills.

Use motion without becoming theatrical.

Use information without becoming cluttered.

THE BIG CREATIVE IDEA

Instead of designing a conventional homepage, create a living property interface.

The homepage should almost feel like the user is already interacting with the platform.

The primary visual object is a beautiful residential property.

The UI should orbit around that property naturally.

For example:

A large architectural photograph sits inside a beautifully proportioned rounded frame.

Small pieces of information are physically integrated around it:

PKR 4.5 Cr

5 Bed
4 Bath
10 Marla

PMC Inspected

DHA Phase 6

Instead of many cards, let information attach naturally to the imagery.

The page should feel composed, not assembled.

HEADER

Use a compact, beautiful header.

PMC wordmark on the left.

Navigation:

Properties
Services
Organizations
Discover

Right:

Search
Sign In
List Property

The header should have subtle translucency or a soft solid surface depending on the background, but NO dramatic glassmorphism.

It should feel almost invisible when scrolling.

HERO — THINK OUTSIDE THE BOX

Do not use the standard centered hero.

Create an asymmetric architectural composition.

Imagine:

LEFT:
small label:

PROPERTY, REIMAGINED

Then a refined headline:

Find a place.
Know it before you go.

Supporting text should be short.

Then a compact search control.

RIGHT:
A large beautifully photographed home.

The house image should feel almost like an architectural magazine cover.

Around the image, integrate tiny interface details.

For example:

A soft floating chip:

PMC VERIFIED

Another:

3D AVAILABLE

Another:

5 BED · 4 BATH · 10 MARLA

These should feel like part of the composition, not random floating cards.

SEARCH

Make the search compact and elegant.

Not a giant rectangle.

Build something resembling a refined physical control panel.

Example:

[ Lahore / DHA Phase 6 ] [ Buy ] [ House ] [ Price ] [ Search → ]

Soft radius.

Beautiful spacing.

Subtle border.

Strong typography.

When interacting, controls morph rather than simply opening.

MORPHING INTERACTIONS

This is extremely important.

Add morphic transitions where components naturally transform into their next state.

Examples:

Search

A compact search bar expands into a refined filter surface.

The original bar remains visually connected to the expanded interface.

Property card

Hovering a property causes the image region to subtly expand while metadata reorganizes around it.

Verification

Clicking:

PMC Inspected

causes the badge to smoothly morph into a compact verification panel.

Saved property

Heart/bookmark icon subtly changes shape and becomes a small confirmation state.

Service category

Selecting:

AC Service

causes the category tile to smoothly transform into the service-request interface.

3D property

Clicking:

Explore 3D

should transition from the property photograph into the interactive 3D experience rather than navigating through an abrupt visual jump.

Motion must feel material and connected.

SOFT UI LANGUAGE

Use:

14–18px standard corner radius

20–28px for major visual surfaces

soft borders

subtle depth

very gentle shadows

restrained elevation

Avoid:

50px pills

giant rounded rectangles

overly inflated components

The softness should come from proportion and curvature, not huge radii.

COLOR DIRECTION

Use bold, saturated PMC brand color accents.

Do not make everything washed-out.

Base:
clean neutral background.

Accent:
strong PMC brand color.

Text:
rich near-black.

Supporting:
warm neutrals.

Status:
strong but restrained green / amber / red.

The colors should appear intentional and alive.

No low-opacity everything.

No hazy pastel interface.

No gradient wallpaper.

TYPOGRAPHY

Use a modern premium grotesk/sans-serif with personality.

The typography should feel editorial.

Avoid:

generic Inter-everywhere appearance

huge startup headings

overly rounded children's-app typography

Use:

strong display typography

compact labels

refined numerical styling for prices

tight metadata

clear hierarchy

Property prices should look particularly beautiful.

IMAGERY

Real architectural photography is critical.

Use:

modern houses

sophisticated interiors

natural light

materials

concrete

wood

stone

landscaping

Do NOT use generic people shaking hands.

Do NOT use fake AI architecture.

The property should be the hero.

VISUAL SURPRISE

Include at least 2–3 moments that make the homepage feel unlike a normal real-estate site.

Possible ideas:

1.

A property image softly reveals its floor-plan outline when hovered.

2.

The PMC verification badge expands into the property's verification passport.

3.

A service category transforms into the actual service request interface.

4.

The property image subtly shifts perspective as the user scrolls.

5.

The 3D Digital Twin section visually transitions from photograph → floor plan → 3D interior.

Do NOT use gimmicks.

The surprise must come from interaction design.

SPACING

Use varied density.

Hero:
moderate breathing room.

Property section:
denser.

Verification:
dense.

Services:
compact.

Footer:
structured.

Create visual rhythm.

The page should feel intentionally paced.

The final homepage should look like something that could realistically win a major web/product design award because the layout, art direction, interaction design and typography are exceptional, not because it uses flashy visual effects.

QUALITY BAR

Pretend you are not generating a website.

Pretend you are designing a flagship digital product that will be shown to a major real-estate company board of directors.

Every component must look intentional.

Every curve must feel considered.

Every piece of information must earn its place.

Every animation must connect one state to another.

Make it feel designed by a specialist, not assembled by an AI.
